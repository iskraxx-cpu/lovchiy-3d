# ЗОК «Ловчий» — 3D-модель

Интерактивная модель защитных ограждающих конструкций от БПЛА на базе сетки «Ловчий» с элементами усиления: восемь типовых решений (ТР-01…ТР-08), сцена удара БПЛА, дополненная реальность (WebXR, Android Chrome).

Страница собирается из исходников альбома (`scene3d.js`), сюда копируется готовый `index.html`.
